# Class Routine Maker (online version)

Runs fully in the browser. No Python, no server. Teachers are saved in each visitor's own browser.

## Files
- index.html     -> landing page
- landing.css    -> landing page style
- routine.html   -> input page (teachers + routine)
- style.css      -> input page style
- script.js      -> what the input page does
- scheduler.js   -> the routine-making logic
- config.js      -> school days, period times, tiffin break (change them here)
- images/        -> logo.png and school.jpg

## Try it on your computer
Double-click index.html (it opens in Chrome). No other step needed.

## Put it online with GitHub Pages
1. Sign in at github.com, click + (top right), then New repository.
2. Name it routine-maker, choose Public, click Create repository.
3. Click "uploading an existing file", drag in everything from this folder
   (index.html, routine.html, the .css and .js files, and the images folder), then click Commit changes.
4. Go to Settings > Pages. Under Branch choose main, keep /(root), click Save.
5. After about a minute your link appears: https://YOURUSERNAME.github.io/routine-maker/
